# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the current `www.fkcesis.lv` favicon to all FK Cēsis MMS parent/public pages and Django admin pages.

**Architecture:** Store the source-site favicon as a local Django static asset and reference it from templates with `{% static %}`. Parent/public pages inherit `templates/base.html`; Django admin pages need a small `templates/admin/base_site.html` override because admin does not inherit the project base template.

**Tech Stack:** Django 5 templates/staticfiles, pytest/pytest-django, ruff, mypy.

---

## Design decisions

1. **Local static copy, not CDN hotlink.**
   - Why: avoids runtime dependency on Shopify CDN URL/version and satisfies the acceptance rule that no external favicon URL is used at runtime.

2. **Use existing template inheritance instead of middleware or view changes.**
   - Why: favicon is static head metadata. `templates/base.html` already controls parent/public `<head>` links, so one line covers those pages.

3. **Admin override only for favicon head content.**
   - Why: Django admin has its own base templates. Django docs support overriding `admin/base_site.html` while extending the original admin template. This keeps admin shell unchanged and avoids copying full admin templates.

4. **Test rendered HTML, not browser pixels.**
   - Why: favicon display is browser behavior. The app contract is that the correct `<link rel="icon">` is rendered and the file exists.

## Test strategy

- Framework: pytest + pytest-django.
- Test parent/public output through `/register/` because it uses `templates/base.html` through `parent_ui/base_parent_page.html`.
- Test admin output through `/admin/` with a forced-login superuser because admin uses independent Django admin templates.
- Test file existence only; do not assert binary content beyond successful download.
- Do not test browser favicon rendering, image dimensions, or cache behavior.

## Acceptance criteria per unit

1. **Static asset**
   - `static/img/favicon.png` exists.
   - File is non-empty PNG fetched from current FK Cēsis site favicon URL.

2. **Parent/public pages**
   - GET `/register/` returns 200.
   - Rendered HTML includes `rel="icon"`, `type="image/png"`, and `/static/img/favicon.png`.

3. **Django admin pages**
   - Authenticated GET `/admin/` returns 200.
   - Rendered HTML includes `rel="icon"`, `type="image/png"`, and `/static/img/favicon.png`.

4. **No external favicon runtime dependency**
   - Templates do not include `fkcesis.lv/cdn` favicon URLs.

- [ ] **Step 1: Download favicon asset**

Run:

```bash
python - <<'PY'
from pathlib import Path
from urllib.request import urlopen

url = "https://fkcesis.lv/cdn/shop/files/FK_Cesis_2.png?crop=center&height=32&v=1741252753&width=32"
out = Path("static/img/favicon.png")
with urlopen(url, timeout=30) as response:
    data = response.read()
if not data.startswith(b"\x89PNG\r\n\x1a\n"):
    raise SystemExit("downloaded favicon is not a PNG")
out.write_bytes(data)
PY
```
