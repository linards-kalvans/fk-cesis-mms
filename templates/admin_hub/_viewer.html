{% comment %}Expects `viewer_tabs`: a list of (label, panel) pairs, where each panel carries `active`, `preview_kind`, and the already-resolved `preview_url` / `download_url` authorized private proxies (empty when the kind has no file), plus `viewer_initial_index`: the index of the first panel with an active document (or None when every tab is empty). The Hub resolves the URLs in its adapter so this fragment never assumes a Document row - a medical permit resolves through its own proxy routes. Rotation and zoom are presentation-only CSS transforms - no stored file is ever modified. Safe native previews: images use the raster image path, PDFs use a titled native iframe, and every other format (including HTML, SVG and office files) gets open/download links only - unsupported content is never embedded. The "Jaunā cilnē" / "Lejupielādēt" toolbar links always follow whichever tab is active: each tab button carries the two authorized proxy URLs (or empty, when that kind has no active document) as data attributes, and viewer.js copies them onto the two toolbar links on load and on every tab switch. The links are never rendered once per-panel here - that is what let them go stale on the wrong tab before this fix. Every available document also carries visible open/download links inside its stage, so the authorized fallback works without JavaScript when native rendering is unavailable. {% endcomment %}
